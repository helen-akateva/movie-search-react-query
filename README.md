# Movie Search with React Query

A modern movie search application built with React, TypeScript, and TanStack Query (React Query). Search for movies using The Movie Database (TMDB) API with features like pagination, detailed movie information, and smooth data caching.

[🎬 Live Demo](https://movie-search-react-query.vercel.app/)

## 📋 Description

This application demonstrates the power of React Query for efficient data fetching and state management. Users can search for movies, browse through paginated results, and view detailed information in a modal window. The app features optimistic UI updates, automatic background refetching, and seamless pagination with cached data.

## 🛠️ Technologies

- **React 19** - UI library
- **TypeScript** - Type-safe JavaScript
- **TanStack Query (React Query)** - Data fetching and caching
- **Vite** - Build tool and dev server
- **Axios** - HTTP client
- **React Hot Toast** - Toast notifications
- **React Paginate** - Pagination component
- **TMDB API** - Movie database
- **CSS Modules** - Scoped styling

## ✨ Features

- 🔍 Real-time movie search
- 📄 Paginated results with smooth navigation
- 🎯 Detailed movie information modal
- ⚡ Optimistic UI with React Query
- 💾 Automatic data caching and background updates
- 🎨 Responsive design
- 🔔 Toast notifications for user feedback
- 🚀 Fast performance with Vite

## 🚀 Deployment

The application is deployed on **Vercel** and automatically updates with each push to the main branch.

## 💻 Local Development

1. Clone the repository:
```bash
git clone https://github.com/helen-akateva/movie-search-react-query.git
cd movie-search-react-query
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open [http://localhost:5173](http://localhost:5173) in your browser

## 📦 Build

To create a production build:

```bash
npm run build
```
